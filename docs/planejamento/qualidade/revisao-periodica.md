# Revisao Periodica

## Revisao Semanal

- [ ] Conferir [ciclos/2026-08](../ciclos/2026-08).
- [ ] Atualizar status das tarefas do ciclo.
- [ ] Mover itens maduros de [backlog](../tarefas/backlog) para o ciclo.
- [ ] Registrar decisoes novas em [decisoes](../decisoes).

## Revisao por Ciclo

- [ ] Conferir [historico](../historico).
- [ ] Revisar pendencias dos modulos em foco.
- [ ] Atualizar [mapa-de-modulos](../mapa-de-modulos) se rotas ou paginas mudaram.
- [ ] Rodar checklist em [checklist-de-revisao](../governanca/checklist-de-revisao).
- [ ] Fazer auditoria leve em [auditoria-de-links](./auditoria-de-links).

## Revisao de Marco

- [ ] Validar se a documentacao operacional bate com o painel real.
- [ ] Validar se a arquitetura documentada bate com o codigo.
- [ ] Verificar notas obsoletas.
- [ ] Arquivar ou substituir decisoes antigas.
- [ ] Atualizar [roadmap](../roadmap).

## Responsabilidade

A revisao deve ser feita pela pessoa que mudou o fluxo ou modulo. Quando a mudanca for ampla, a revisao deve passar por alguem de operacao e alguem tecnico.
