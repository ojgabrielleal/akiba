# Mudancas que Exigem Doc

## Sempre Exige

- [ ] Nova pagina.
- [ ] Novo modulo.
- [ ] Nova permissao.
- [ ] Nova action com regra de negocio relevante.
- [ ] Nova integracao externa.
- [ ] Novo status de entidade.
- [ ] Alteracao de fluxo operacional.
- [ ] Mudanca em regras de radio, locucao, tarefas, postagens ou administracao.
- [ ] Mudanca em como relatorios calculam indicadores.

## Geralmente Exige

- [ ] Refatoracao que muda estrutura de controllers, actions, filters ou resources.
- [ ] Mudanca em nome de rota.
- [ ] Mudanca em campo obrigatorio de formulario.
- [ ] Mudanca visual que altera como o usuario executa um fluxo.
- [ ] Mudanca em processo de contribuicao, release ou revisao.

## Normalmente Nao Exige

- [ ] Ajuste pequeno de estilo sem alterar fluxo.
- [ ] Correcao de typo interno.
- [ ] Refatoracao local sem mudanca de comportamento.
- [ ] Teste novo para comportamento ja documentado.

## Em Duvida

Se houver duvida, adicionar uma nota pequena ou justificar na PR por que nao precisa. Documentacao curta e correta custa menos do que regra perdida.
