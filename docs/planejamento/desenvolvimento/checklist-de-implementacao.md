# Checklist de Implementacao

Use antes de encerrar uma tarefa de desenvolvimento.

## Codigo

- [ ] Mudanca segue padroes do projeto.
- [ ] Controllers continuam finos.
- [ ] Actions concentram regra de negocio quando aplicavel.
- [ ] Requests validam entradas de formulario quando aplicavel.
- [ ] Policies ou gates foram considerados.

## Testes

- [ ] Testes foram adicionados ou atualizados quando relevante.
- [ ] Cenario principal foi validado localmente.
- [ ] Regressao provavel foi considerada.

## Documentacao

- [ ] Verificado se a mudanca exige documentacao em [mudancas-que-exigem-doc](./mudancas-que-exigem-doc).
- [ ] Nota de modulo atualizada quando necessario.
- [ ] Guia operacional atualizado quando necessario.
- [ ] Decisao registrada quando necessario.
- [ ] Roadmap, ciclo ou backlog atualizado quando necessario.

## PR

- [ ] Template de PR preenchido.
- [ ] Justificativa de documentacao incluida.
- [ ] Breaking changes documentadas, se existirem.
