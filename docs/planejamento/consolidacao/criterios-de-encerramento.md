# Criterios de Encerramento

## Ciclo Inicial de Documentacao

O ciclo inicial pode ser considerado encerrado quando:

- [ ] a equipe validar o escopo dos modulos;
- [ ] pelo menos uma pessoa tecnica revisar [arquitetura](../arquitetura);
- [ ] pelo menos uma pessoa de operacao revisar [operacao/index](../operacao/index);
- [ ] uma pessoa nova conseguir seguir [onboarding](../adocao/onboarding);
- [ ] a auditoria local rodar sem problemas;
- [ ] pendencias do [backlog](../tarefas/backlog) forem priorizadas;
- [ ] o formato oficial de compartilhamento for escolhido;
- [ ] aceite final for registrado em [historico](../historico).

## Aceite Minimo

Para usar a documentacao no dia a dia, o aceite minimo e:

- [index](../index) funciona como entrada;
- [mapa-de-modulos](../mapa-de-modulos) cobre o painel privado;
- [planejamento-operacional](../planejamento-operacional) orienta ciclos e tarefas;
- [operacao/index](../operacao/index) orienta fluxos principais;
- [governanca/index](../governanca/index) explica manutencao.

## Depois do Encerramento

Depois do encerramento, novas mudancas devem seguir:

- [manutencao](../governanca/manutencao)
- [checklist-de-revisao](../governanca/checklist-de-revisao)
- [criterios-de-decisao](../governanca/criterios-de-decisao)
- [auditoria-local](../automacao/auditoria-local)
