# Painel Privado

## Quem Usa

Equipe interna com acesso ao painel.

## Quando Usar

Sempre que for acompanhar tarefas, publicar conteudos, operar radio, gerenciar usuarios ou consultar indicadores.

## Fluxo Principal

1. Acessar `/panel`.
2. Fazer login.
3. Entrar no Dashboard.
4. Revisar avisos, tarefas, materias recentes e calendario.
5. Navegar para o modulo necessario pelo menu lateral.

## Resultado Esperado

- Usuario autenticado acessa apenas modulos permitidos.
- Dashboard mostra uma visao rapida do trabalho do usuario.
- Acoes administrativas ficam concentradas em modulos privados.

## Cuidados

- Permissoes controlam o que aparece no menu e o que pode ser feito.
- Nem todo usuario deve ter acesso a administracao, relatorios ou lixeira.
- Tarefas atrasadas ou em revisao devem ser tratadas como prioridade operacional.
