# Governanca

Esta area define como manter a documentacao de planejamento viva, coerente e util para o projeto.

## Guias

- [manutencao](./manutencao)
- [checklist-de-revisao](./checklist-de-revisao)
- [templates](./templates)
- [criterios-de-decisao](./criterios-de-decisao)

## Principios

- Toda nota deve ter um objetivo claro.
- Toda decisao estrutural deve ser registrada.
- Toda mudanca relevante em fluxo deve atualizar a documentacao operacional.
- Toda mudanca relevante em codigo deve atualizar a documentacao tecnica quando alterar arquitetura, modulo, permissao ou comportamento esperado.
- O VitePress deve ser tratado como interface principal de leitura; o repositorio continua sendo a fonte versionada.
