# Publicacao

Esta área define como compartilhar, empacotar e consumir a documentação do Akiba como site VitePress.

## Guias

- [formas-de-compartilhamento](./formas-de-compartilhamento)

## Objetivo

- permitir que a documentação circule sem perder contexto;
- evitar publicar informações sensíveis por acidente;
- manter o Markdown como fonte principal do VitePress;
- facilitar leitura pelo site local ou por um deploy estático.
