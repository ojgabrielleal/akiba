# Navegacao no Site

## Como Acessar

Com os containers ativos, abra:

```txt
http://localhost:5174/
```

Comece por:

1. [Planejamento Akiba](../index)
2. [Onboarding](../adocao/onboarding)
3. [Mapa de leitura](../adocao/mapa-de-leitura)
4. página do módulo ou fluxo desejado

## Links Internos

Links internos usam Markdown padrão e funcionam diretamente no VitePress.

Exemplos:

- `[radio](../modulos/radio)` aponta para `docs/planejamento/modulos/radio.md`.
- `[operacao/index](../operacao/index)` aponta para `docs/planejamento/operacao/index.md`.
- `[backlog](../tarefas/backlog)` aponta para `docs/planejamento/tarefas/backlog.md`.

## Busca e Sidebar

Use a busca local do VitePress para encontrar termos, módulos e decisões. Use a sidebar para navegar por áreas: planejamento, módulos, operação, governança, adoção, qualidade, automação, desenvolvimento e consolidação.
