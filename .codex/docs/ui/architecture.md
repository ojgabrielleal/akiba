# Arquitetura

- Preserve a estrutura atual (`pages`, `layouts`, `components`, `widgets`, `store`, `utils`).
- `pages`: composição das telas.
- `layouts`: estrutura compartilhada.
- `components`: elementos reutilizáveis.
- `widgets`: blocos de domínio.
- `store`: apenas estado compartilhado.
- `utils`: lógica sem UI.
