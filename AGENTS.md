# Projeto

## Frontend
- Leia somente se necessário antes de alterar UI, leia `.codex/docs/ui-guidelines.md`.

## Factories
- Leia somente se necessário antes de alterar factories/seeders, leia `.codex/docs/factory-guidelines.md`.

## Ambiente
- Antes de comandos PHP, Node ou MySQL:
  `./run.sh up`.

## Commit
Ao pedir commit:
- execute `./run.sh npm run build`;
- revise `git status` e `git diff`;
- responda apenas com a mensagem de commit.
